# u06-historia — « Madrid a oscuras » (6 compositions : 10,4 + 8,6 + 5,6 + 8,6 + 6,8 + 8,8 s)

Décor unique du kit : `mnPlaza` (Plaza Mayor de nuit, marché de Noël, étals à bougies, grand sapin éteint, étoile). Personnages : Nacho (bonnet rouge, trottinette), Rosa (churrera), Paloma (loterie, bonnet de laine), Álex, Marina, Quetzal, Sombra (`QArt.sombra*`). Bordure `madridnoche`. Toutes les lumières (`.mn-lights`, `.mn-treelights`, `.mn-star-lit`) sont **éteintes** (opacité 0) sauf bougies `.mn-candle` qui respirent (cycles ≥ 1 s, ≤ 0,5 d'amplitude).
Mouvement sûr : aucune lumière ne s'allume en < 0,3 s ; la Sombra éteint les guirlandes une à une par fondu 0,6 s (≤ 2 par seconde) ; pas de flash.

1. `-1` **Plan 1** : plan large de la place sombre, caméra qui pousse vers le groupe ; Nacho arrive en trottinette par la droite (« ¡Madrid está a oscuras! ») ; champ / contre-champ sur Marina (« ¿A oscuras? »).
2. `-2` **Plan 2 / réplique 1** : l'étal de Rosa, vapeur qui monte (ellipses douces), tasses de chocolat, file vide ; Rosa tend une tasse.
3. `-3` **Plan 2 / réplique 2** : Nacho au milieu des étals, cloche muette (Real Casa de Correos au fond) ; haussement d'épaules.
4. `-4` **Plan 3 / réplique 1** : le grand sapin éteint ; la Sombra monte et éteint les dernières guirlandes une à une ; Paloma serre ses billets.
5. `-5` **Plan 3 / réplique 2** : Paloma en gros plan (« ¡Esa Sombra se lleva hasta mis villancicos! »), notes de villancico qui s'effacent.
6. `-6` **Plan 4** : travelling vertical jusqu'à l'étoile du sapin ; reflet vert pulsé (halo doux), le Quetzal la montre du bec ; Paloma et les enfants.
